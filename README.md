# 📌 Project Overview

The **Neighborhood Organization Dashboard** is an interactive data visualization project developed using **Power BI** to manage and analyze neighborhood financial and organizational activities.

The dashboard provides a centralized view of:
- Expenses
- Payment methods
- Transaction details
- Amount distribution
- Expense tracking
- Member-based financial analysis

The project helps organizations monitor financial records efficiently through visual analytics and interactive reports.

---

# 🎯 Objectives

The major objectives of this project are:

- Analyze neighborhood financial transactions
- Visualize expense distribution
- Track payment methods
- Create an interactive dashboard
- Improve financial monitoring
- Simplify data analysis using visual reports

---

# 🧠 About the Dashboard

The dashboard provides insights into:
- Total expenses
- Expense categories
- Amount spent by members
- Payment mode analysis
- Monthly transaction tracking

Using Power BI visualizations, users can easily understand spending patterns and financial records.

# 📊 Dashboard Visualizations

The dashboard contains multiple visual reports.

---

# 📌 1. Sum of Amount by Given To

### Visualization:
Bar Chart

### Purpose:
Displays:
- Total amount distributed to individuals
- Expense comparison between members

### Insights:
- Identifies highest spending categories
- Shows financial distribution patterns

---

# 📌 2. Count of Given To by Mode of Payment

### Visualization:
Line/Area Chart

### Purpose:
Analyzes:
- Payment methods used
- Number of transactions

### Payment Methods Included:
- Cash
- Online Transfer
- GPay
- Bank Transfer
- Cheque

---

# 📌 3. Transaction Details Table

### Visualization:
Interactive Table

### Displays:
- Expense Type
- Expense Description
- Amount
- Month
- Year
- Person Name

This section helps users track detailed financial records.
